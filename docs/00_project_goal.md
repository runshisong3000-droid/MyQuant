## MyQuant 项目目标

### 什么是 MyQuant

MyQuant 是一个面向 A 股的 AI 量化选股与可视化特征学习平台。

### 不是什么

- **不是普通 Demo**：这不是一个简单的机器学习演示项目
- **不是直接实盘系统**：当前结果不能直接用于实盘交易

### 当前目标

1. **研究平台**：提供完整的因子研究能力
2. **可视化特征学习**：展示 AI 如何从原始量价序列学习特征
3. **可信度审计**：确保所有因子和模型都经过严格的可信度检查

### 核心流程

```
真实数据 → 数据清洗 → 公式因子 → neural factors → 因子评价 → Gatekeeper 审核 → 截面排序模型 → 回测 → 可信度审计 → 可视化报告
```
