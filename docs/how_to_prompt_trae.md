# how_to_prompt_trae.md

## 如何使用短提示词

### 快捷命令

以后你可以用一句话让 AI 按模板执行：

| 命令 | 作用 |
|------|------|
| "按 bug_fix 模板执行" | 修复 bug |
| "按 audit 模板执行" | 可信度审计 |
| "按 dashboard 模板执行" | 创建/修改可视化 |
| "按 explain_code 模板执行" | 解释代码 |
| "按 neural_feature_learning 模板执行" | 神经特征学习开发 |

### 文件分工

| 文件/目录 | 用途 |
|-----------|------|
| `.trae/rules/` | 短硬规则（必须遵守的规则） |
| `AGENTS.md` | 项目长期上下文（项目定位、状态、规则） |
| `docs/` | 详细说明文档（架构、流程、说明） |
| `prompts/` | 任务模板（每种任务的标准流程） |
| `.agents/commands/` | 快捷命令（一句话调用模板） |

### 规则文件

- 只放简短的规则
- 每条规则不超过一行
- 格式："- 规则内容"

### AGENTS.md

- 项目整体说明
- 当前状态
- 开发铁律
- 标准工作流
- 用户背景

### docs/

- 详细的技术文档
- 架构说明
- 使用指南
- 概念解释

### prompts/

- 每种任务类型的标准流程
- 模板化的操作步骤
- 确保一致性

### .agents/commands/

- 一句话命令
- 指向对应的模板
- 方便快速调用

### 示例

**用户说：** "按 bug_fix 模板执行"

**AI 做：**
1. 读取 AGENTS.md 了解项目规则
2. 读取 prompts/01_bug_fix.md 了解流程
3. 按模板步骤处理用户的问题
