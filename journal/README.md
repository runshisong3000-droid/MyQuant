## 关于这个日志

这个日志系列记录了 MyQuant 项目的开发过程。不仅是技术工作记录，也包含了开发过程中的思考、困惑、突破和心情。

**为什么要写这个？**

量化开发是一个复杂的过程，很多决策和思考过程如果不记录下来，很快就会遗忘。这个日志希望捕捉那些"为什么这样做"的思考，而不仅仅是"做了什么"。

**日志结构**

每篇日志通常包含：
- 📋 今日目标
- 🔧 技术工作
- 💡 思考与洞察
- 😊 心情与感受
- 📝 遗留问题
- 🎯 明日计划
