# 06_run_tests.md

## run_tests 模板

当用户说"按 run_tests 模板执行"时：

### 步骤

1. **找出相关测试文件**
   - 定位与问题相关的测试
   - 列出测试文件列表
   - 说明测试覆盖范围

2. **先运行 pytest**
   - 执行相关测试
   - 记录测试结果
   - 输出详细信息

3. **如果失败，解释失败原因**
   - 分析失败原因
   - 定位问题代码
   - 说明影响范围

4. **不要直接改**
   - 不自动修复
   - 不修改代码
   - 保持原始状态

5. **等用户确认后再修**
   - 说明修复方案
   - 等待用户确认
   - 不擅自修改

6. **修完后重新运行**
   - 运行测试验证修复
   - 运行 pipeline 验证
   - 输出最终结果

---

**适用场景：** 运行测试、验证代码
