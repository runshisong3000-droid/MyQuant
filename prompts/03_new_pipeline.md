## new_pipeline 模板

当用户说"按 new_pipeline 模板执行"时：

### 步骤

1. **先说明为什么需要新 pipeline**
   - 明确需求
   - 解释目的
   - 说明价值

2. **不破坏旧 pipeline**
   - 保持向后兼容
   - 不修改现有代码
   - 创建独立文件

3. **创建配置**
   - 添加配置项
   - 合理默认值
   - 文档说明

4. **创建脚本**
   - 创建新的 pipeline 脚本
   - 添加详细日志
   - 每步输出状态

5. **创建测试**
   - 编写测试用例
   - 验证功能正确性
   - 确保测试通过

6. **使用真实数据**
   - 不使用模拟数据
   - 数据来源可追溯
   - 记录数据质量

7. **每一步打印信息**
   - shape（数据形状）
   - 耗时
   - OK/WARN/FAIL 状态

8. **输出报告**
   - 生成实验报告
   - 记录结果
   - 分析结论

9. **不使用模拟数据**
   - 必须真实数据
   - 不生成假数据

10. **不默认 GPU / 云算力 / LLM API**
    - 默认 CPU
    - 本地数据
    - 学生笔记本模式

---

**适用场景：** 创建新的研究 pipeline
